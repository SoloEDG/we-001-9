# 灰烬渡口

安装：`npm ci`

本地启动：`npm run dev`，打开终端显示的地址。

Docker 启动：`docker compose up --build`，访问 http://localhost:18071。

## 战斗影像导出

右侧「影像导出」面板可把选定的战斗步骤区间导出为可播放视频（MP4 / WebM）。

- **离屏渲染固定快照**：导出开始时先把所选事件的 `before/after` 历史快照深拷贝固化，
  之后在独立的离屏 Canvas 上绘制，不录制当前界面。导出过程中切换选中角色、拖动回放进度
  都不会改写成片内容。
- **同帧时间轴对齐**：每个步骤的移动路径、技能连线与伤害/治疗提示绘制在同一帧，
  画面同时包含地图变化、单位生命状态与行动顺序。
- **可配置画幅与停留**：支持 16:9、9:16、1:1、4:3 四种画幅，每步停留时间 0.4–3 秒可调，
  面板实时显示预计时长与逐帧导出进度。
- **编码兼容**：启动时用 `MediaRecorder.isTypeSupported` 探测本机能力，目标编码不支持时
  提示改用替代格式并禁用导出按钮。
- **可取消、无半成品**：长片段导出途中可取消，立即停止媒体轨道并释放离屏画布等绘制资源；
  只有编码出完整 Blob 才触发下载，取消或失败都不会留下文件，且战斗数据与当前浏览位置原样保留。
